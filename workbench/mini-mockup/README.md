# Mini-CD 五视角样机

此目录集成用户在 [Mini CD 样机工作台](https://mini-cd-mockup-studio.hazyscarf261.chatgpt.site) 开发的静态站点，源版本为 `bacf8cd8ca69430f5dd29e81fab85136ed3ac210`。原站点的五张外壳照片、透视贴图渲染器和本地项目保存功能保留在此目录。

在本地工作台生成三件套后，通过 2D 设计页的“**五视角样机**”打开 `/mini-mockup/?jid=<项目 ID>`。页面首次打开时从本地 `/api/design/state` 和 `/api/design/file` 读取封面、封底、封面背面、内盘底、盘面五张组件图；有已保存的样机调整时优先恢复本浏览器的项目。点击“同步专辑组件”可以重新读取 2D 组件。不同项目 ID 使用不同的浏览器保存记录。

此版本使用 **五张固定角度的实物照片做样机透视合成**，可切换视角、调整贴图、导出 PNG；它不是可任意旋转、开合的 3D 几何模型。2D 印刷组件仍由原设计工作台处理。

根据用户提供的实物装配视频，补入右侧封、左侧封、左侧封背面三张 4.4 × 38 mm 的组件图，按折回纸套的可见面映射到侧面。旧浏览器项目首次升级仅补入缺少的侧封，保留已有五张图片的调整与四角校准。`assemblyVersion` 记录此次补入，移除侧封后不会在每次刷新时自动恢复。侧封的透视位置仍属于照片标定，需按实物继续校核。

打开后朝向观察者的封面背面（`inside`）是露出的纸面，透明盒盖位于纸张后方。此面仅叠加盒沿及四个压纸卡扣的前景，不对整面叠加塑料明暗或高光。闭合时的外封面与托盘的遮挡关系分别处理。
