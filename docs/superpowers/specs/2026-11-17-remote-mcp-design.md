# 工作台远程 MCP 部署设计

用户已确定：其他电脑和云端 Agent 直接调用平台；部署到已有 Hostinger Ubuntu 服务器；域名 music.haoquanwo.cloud，用户在 Hostinger 添加 DNS。

## 服务与数据

独立 Docker Compose 项目，接入已有 dokploy-network 和 Traefik，独立路由与证书。既有工作台只监听容器内 127.0.0.1:8765；网关监听 8080，提供登录保护的网页和 /mcp。服务器现有其他服务保持独立。

使用官方 Python MCP SDK，Streamable HTTP，无状态协议会话；通过 Authorization Bearer 配置调用凭据。首版连接支持可配置请求头的 MCP 客户端，不实现浏览器 OAuth 授权流程。网页使用独立 Basic 登录凭据。下载提供限时签名链接。

素材、作品、上传及任务数据库保存于持久目录。现有本机作品复制到服务器，不覆盖本机数据，不迁移本机加密 API 凭据。服务器安装中文字体。源码和部署配置不保存明文凭据。

## 工具与任务

提供平台状态、音乐搜索、歌手专辑、专辑曲目、作品列表、图片上传、单张与批量 Mini CD、钥匙扣等原有制作、八视图商品图、任务查询及下载列表。

耗时生成返回 task_id；SQLite 持久队列串行处理，避免高清出图耗尽服务器内存。服务重启时标记中断任务，保留已生成文件。批量生成每本专辑均制作其自身八视图，并包含总预览与八张独立商品图；ZIP 按专辑分目录，素材与商品图分目录。

八视图使用 Chromium 加载原渲染模块，不重新制作模型。服务器后台生成与网页同源。文件访问限定已知作品目录，工具参数禁止任意本地路径；上传最大20MB，任务限制批量数量和图片尺寸。

## 验证与交付

验证未授权请求拒绝、真实MCP握手和工具调用、任务状态、文件路径限制、签名过期、真实三件套与八视图出图以及ZIP目录；检查独立域名HTTPS和现有网站运行情况。提供MCP地址、客户端配置和独立保存的访问凭据。
