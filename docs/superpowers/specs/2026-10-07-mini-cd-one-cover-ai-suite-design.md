# 迷你 CD：一张封面生成整套组件

## 目标与范围

在现有拾音工坊的迷你 CD 功能中，用户上传一张专辑封面，启动一次生成任务，工作台自动完成同一视觉风格的所有独立组件、三件套展开图、技术总览图和打印文件。生成结束后，用户可以用自然语言只修改任意一个组件，其余组件保持原样。此功能沿用现有工作台、作品库和 Mini CD 物理规格，不创建第二套工作台。

现有 `tools/spec_minicd.py` 是尺寸、顺序和裁切位置的唯一来源：盘面外径 40mm、内孔 5mm；封面折件 82×41mm（两个 41×41mm 页面）；封底展开条 111.2×38mm，按 4.4／49／4.4／4.4／49mm 排列。用户这次提供的图片用于确认组件职责和视觉效果，不替代物理规格。

## 用户流程

1. 用户在迷你 CD 页面上传封面，并点击“一键生成整套”。已有音乐搜索选中的封面也可走同一入口。正常情况下不要求逐件填写文字、选择模板或逐件确认。
2. 工作台从封面识别专辑名和歌手，调用现有网易云／QQ 音乐元数据搜索，按专辑和歌手匹配真实曲目、顺序、时长与发行信息。高置信度匹配直接继续；多个候选时只请用户选择一次；查不到时请用户提供真实曲目。创意标语可以由 AI 撰写，真实曲目不能由 AI 猜造并冒充检索结果。
3. 工作台分析封面的视觉元素，形成一次任务共用的风格设定。图片模型在同一任务中自动生成所有需要的新组件，呈现统一的颜色、人物、材质、字体气质与文字布局。正面封面默认采用上传原图。
4. 用户在结果页查看每张独立组件及合成的展开图、技术总览图、A4 打印文件，下载单件或整套 ZIP。作品进入现有作品库。
5. 用户可选中一个组件输入修改描述，例如“只把盘面背景改为蓝色，保留人物和标题”。系统仅重绘该组件，重新装配受其影响的合成图与 ZIP，不重绘其他独立组件。

## 组件与输出

| 独立组件 | 来源与内容 |
| --- | --- |
| 封面正面 | 上传的原封面；默认保持原样 |
| 封面背面／内页 | AI 根据封面扩展的新场景和文字 |
| CD 盘面 | AI 重新构图，避开中心孔 |
| 右侧封 | AI 生成与整套一致的窄幅画面、标题 |
| 封底 | AI 生成完整视觉和文字布局，包含真实曲目及现有固定封底内容 |
| 左侧封 | AI 生成窄幅画面与文字 |
| 左侧封背面 | AI 生成窄幅画面与文字 |
| 内盘底 | AI 生成隐藏主视觉／延展场景 |

上述独立图片全部由**一次任务**自动生成并分别保存，不要求用户逐件点击。程序按固定物理尺寸装配封面折件、封底展开条和盘面，另输出白底三件套技术总览、A4 PNG／PDF、规格数据及 ZIP。组件像素尺寸以目标打印 DPI 和 `spec_minicd.py` 计算；AI 返回图片不得决定物理尺寸或折线。

## 文字与固定内容

AI 参与所有组件的画面、字体风格、标题、装饰文案和排版。现有工作台的固定封底字段与规则继续使用，包括真实曲目和时长、唱片公司／版权文字、条码及其指定位置。生成请求带上这些内容，输出后再逐项核对。模型写错或漏写必需内容时，该组件标为“需修正”；系统先尝试局部重新生成，仍不正确时使用匹配当前视觉风格的精确文字层修复，并保留用户查看与修改的能力。不得把含错误曲目、失真条码或漏掉固定版权内容的图标记为可打印成品。

已有的字体与文字编辑功能保留在高级编辑中，默认流程不要求用户操作。原有非 AI 模板生成仍可作为无模型配置时的明确备选，界面须如实说明其效果与 AI 生成不同。

## 多模型配置

设置页可保存多个命名配置，每项包含服务商、模型、接口地址（服务商允许时）、密钥、连接测试结果、是否支持参考图编辑。用户指定一个迷你 CD 默认图片模型，也可在单次任务中改选。首批实现 OpenAI 图片接口与 Google Gemini 图片接口两个适配器；其他服务商以后按实际图片生成／编辑能力添加，不能因为文本接口兼容就标为可用于图片。文字识别与元数据整理可使用独立文字模型配置，但不作为一键生成的额外必填项。

密钥仅由本机后端读取和保存，不写入仓库、不返回前端明文。用户在本机设置并测试配置之后才调用收费接口；未配置时给出明确提示。封面发送给用户选定的模型服务商前，界面说明所选服务商。

## 结构与失败处理

在现有 `workbench/design_service.py` 外增加独立的 AI 任务编排与服务商适配层，复用现有音乐检索、`tools/design_parts.py`、`tools/make_minicd.py`、`tools/make_minicd_sheet.py` 及作品库入口。任务保存原封面、识别结果与来源、实际使用的曲目数据、风格设定、每件图片的版本和提示词、提供商与模型、尺寸校验及修正记录。后续单件修改只更新目标组件版本和依赖的合成文件。

生成页显示识别、查歌、各组件生成、文字校验、装配、完成等状态。某个组件失败时保留已完成图片，可单件重试。模型不可用、密钥错误、额度不足、超时、音乐源限流、专辑识别冲突、文字校验失败都给出具体提示；不能以模板结果冒充 AI 成功。

## 验收

- 上传单张封面并启动一次任务后，自动得到八张独立组件、三件套合成、技术总览和打印文件；正面封面与上传图一致。
- 所有展开尺寸、分段顺序、孔位、条码与折线符合 `spec_minicd.py`；固定封底内容和真实曲目正确且可读。
- 能说明曲目来自哪个来源；匹配失败时接受用户补充，不编造真实曲目。
- 保存并切换多个模型配置；密钥不进入页面响应、日志或 Git。
- 修改单个组件后，其他组件文件保持不变，合成图与 ZIP 更新。
- 使用模拟图片服务完成端到端测试；真实模型调用需在用户完成本机密钥配置后验证。

## 方案取舍

采用“一次任务、独立组件生成、固定规格装配”。一次让模型直接绘制整张技术展示板虽然调用更少，但尺寸、折线和小字难以控制；纯原图裁切与模板排版能离线运行，却达不到用户提供的场景扩展效果。独立组件方案支持同一任务自动生成整套，也支持以后精准修改一件。
