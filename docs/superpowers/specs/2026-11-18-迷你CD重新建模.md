# 迷你 CD 独立模型重建

用户在确认真实三维模型原型方案后明确要求“那你自己重新建模”。本轮直接制作独立原型，暂不接入8765，不修改已撤回的背景功能，不覆盖旧blend，不提交或推送。

主体闭合尺寸53×45×8mm（不含挂孔）；光盘40mm，中孔5mm。以本地实物参考照片为结构依据，采用真正的实体薄壁杯形盒底、翻转盒盖和固定侧槽，盒盖绕共用铰链轴开合。内盘底是单张连续纸，透过透明盘托可见；正封面和内页为同一纸片两面。盘托和光盘分别可隐藏。所有挂孔由几何镂空形成，无照片壳体贴图。

细节包括圆角壁厚、挂孔支架及内外唇、两端铰链轴套、四个半圆压纸舌、边缘加强筋、中心弹性盘扣和卡槽。未实测壁厚、挂孔、卡扣细节为可调估算，不作制造CAD。

交付独立.blend、可复现Python构建脚本、GLB和正面/斜视/展开装盘三个角度的透明材质渲染，另附灰模及同一机位白底/深色背景对照。贴图只用于纸张和光盘图案，透明壳使用真实体积、IOR及灯光反射。

核查主体尺寸、网格边界/非流形边、光盘孔径、挂孔贯通及铰链父子变换。检查正面纸张未拉伸、透明盘托未重复、深色背景壳体轮廓、地面接触阴影与反光。物理细节估算和最终视觉验收需诚实说明。
