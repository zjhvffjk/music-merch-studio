# 预览对象点选与统一文字格式栏

日期：2026-09-23

## 目标

将迷你 CD 设计页从“按文字类别分别设置字体”改为所见即所得的对象编辑：用户在实时预览中点击文字，即可通过一套统一格式栏编辑其字体、字号、粗体、斜体和颜色。预览和最终印刷生成使用同一份对象格式数据。

## 范围

本轮只实现对象点选和格式编辑。文字位置继续由模板与安全区控制；不提供自由拖动、缩放或改变对象位置。

## 交互

1. 预览图上为可编辑文字渲染透明命中区域。可选对象包含专辑标题、歌手、中文文案、英文文案、曲目与信息，以及三条物理侧封。
2. 点击对象后，显示轻量选中框和对象名称；顶部统一格式栏读取该对象当前设置。
3. 格式栏包含字体、字号、加粗、斜体和字体颜色。操作后立即请求预览；侧封字号仍以毫米表达，并按 4.4×38 mm 成品安全区限制。
4. 生成按钮与预览请求传递同一份 `textAppearance` 数据。后端对每个对象规范化字体、字号、样式与颜色后绘制。
5. 原“字体”工具页改为字体库说明与选择入口，不再要求用户通过角色列表查找目标文字。

## 数据与渲染

前端维护按对象 ID 存储的 `textAppearance`。已有 `spineAppearance` 迁移为相同对象模型的一部分，保留旧项目兼容读取。预览命中区域以成品画布的实际部件尺寸映射，不以网页缩略图尺寸作为成品尺寸。

后端将标题、歌手、文案、信息和侧封的样式统一应用至实际 PNG。字体颜色、字体与字号不只影响界面按钮，必须进入最终文件。

## 验证

- 点击每类文字，格式栏显示对应状态。
- 修改字体、颜色、字号或粗斜体后，预览立即变化。
- 生成成品后，抽查每类对象与预览颜色、字体和样式一致。
- 侧封仍不超出 4.4×38 mm 安全区。
- 保留现有字体库、侧封模板、搜索和导出回归测试；增加对象格式在固定模板与生成路径中生效的测试。
