# 热门批量制作与单曲制作页统一设计

## 目标
“按热门生成”进入与单曲制作一致的商品配置页；用户先选热门歌曲数量、再选择输出商品和调整制作参数，最后才开始批量生成。

## 页面结构
- 顶部：保留返回歌曲列表、歌手名和“热门歌曲批量制作”说明。
- 主卡：以歌手头像或第一首热门歌封面作为视觉锚点，显示当前数据源与可制作歌曲数量。
- 第一组卡片：热门前 5、10、15 首，只能选择一个数量。
- 第二组卡片：钥匙扣商品图、电商白底图、黑胶播放界面；可多选，NFC 卡维持“即将加入”。
- 参数区：完全复用单曲“制作细节参数”，包含播放文案、主图尺寸、白底画布和底色、黑胶尺寸、显示规则、商品拼版与播放界面打印输出。
- 页底：明确显示已选数量和商品数；取消和开始批量制作。开始后仍进入现有批量结果页、整组总览和打印交付。

## 数据与交互
- 数量默认为 5，商品默认全选。
- 所有细节参数继续同步到现有隐藏参数字段，后端无需新增协议。
- 点击开始时设置 `MODE='artist'` 和 `TOP=选中数量`，并将商品开关回写到 `#p_keychain`、`#p_shop`、`#p_vinyl` 后调用既有 `#btnGo`。
- 返回和浏览器后退恢复歌曲列表；进入批量页不会产生打印界面。

## 成功标准
- 批量与单曲页面的商品卡、参数区、按钮层级一致。
- 选择任意热门数量和商品组合后，生成任务只产生所选商品且歌手热门数量正确。
- 返回歌曲列表、页面后退和任务结果后的现有导航不回归。
