# 商品图自定义水印

用户已确认：文字和上传 Logo 均支持；在八视图样机右侧设置、实时预览，单张、三视图、八视图及批量商品图统一生效。

设置默认关闭，支持文字、Logo 或两者，字号/图标宽度、透明度、颜色、位置、旋转及平铺。设置保存到浏览器，跨专辑共享。原素材与印刷文件不添加水印。导出仍为原尺寸无损 PNG，最终画布只叠加一次水印。

watermark.js 负责校验、浏览器持久化、Logo 加载与绘制；watermark-controls.js 负责右侧表单及状态；app.js 在预览和导出快照间传递设置；renderer.js 在最终导出画布上叠加。变更设置通过既有消息使导出缓存失效。验证空文字、无 Logo、透明 Logo、异常参数、平铺、跨专辑恢复和最终导出。
