# 商品图水印实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 可自定义文字和Logo水印并统一应用到商品图。
**Architecture:** 独立设置和绘制模块，右侧表单实时更新，最终画布叠加一次。
**Tech Stack:** 原生 JS、Canvas 2D、IndexedDB。
**Spec:** ../specs/2026-11-18-商品图水印-design.md

## Global Constraints

- 保留用户已确认的盒体比例、布局及8K无损PNG。
- 设置跨专辑共享，原素材和印刷图不加水印。

## Review Focus

- 空文字及缺少Logo不绘制；无效Logo显式报错。
- 设置异常值校验且尺寸保持在画布内。
- 透明Logo保留透明度；异步加载不会覆盖较新设置。
- 单张和总览仅在最终画布绘制一次。
- 批量隐藏iframe加载共享设置，变更后导出作废重生成。
