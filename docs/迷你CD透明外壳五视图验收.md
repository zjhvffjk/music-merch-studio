# 迷你 CD 透明外壳：五张实物图验收基准

用户给定的外壳外尺寸为 **宽 53 mm × 高 45 mm × 厚 8 mm**，顶部挂孔不计入 45 mm。印刷展开尺寸与外壳尺寸分别管理。

空盒结构照片保存在 `workbench/mini3d-src/public/reference/`。用户最新给的七张带专辑画面的商品图保存在同目录的 `final/`；其中五种不同交付状态如下。它们是**效果参考**，不是当前 WebGL 模型的渲染结果，也不能直接当作精确制造图纸。

| 序号 | 原图 | 必须呈现的状态与结构 |
| --- | --- | --- |
| ① | `final/01.png` | 闭合正面；专辑封面透过透明盒盖可读，左侧竖向铰链、顶部重合挂孔及厚边可辨。 |
| ② | `final/03.png` | 闭合背面；封底画面透过盒底可读，盘托的圆形痕迹与透明卡扣仍有层次。 |
| ③ | `final/04.png` | 180° 平铺；左侧内页、右侧盘面，两个挂孔分开显示，铰链连接完整。`final/02.png` 是同类参考。 |
| ④ | `final/05.png` | 斜向半开；展示盒体深度、内页、光盘、铰链与折射。`final/06.png` 是从外侧看的补充参考。 |
| ⑤ | `final/07.png` | 平铺取盘；光盘从卡扣取出并放在盒外，盘面直径 40 mm、中心孔 5 mm。 |

五张效果图应由**同一个可开合的 3D 结构模型**切换状态与机位生成。透明外壳要有连续的模压边框、内外壁、盘槽、中央弹性卡扣、闭合接缝、铰链、挂孔，以及环境反射和接触阴影。不能用五张静态照片冒充模型生成结果。

当前工作台仅有可交互的程序化预览模型。它能表达大致结构与贴图位置，但边缘层次、塑料厚度和透明材质摄影效果尚未达到这些参考图；因此当前导出的 PNG 仅称“预览图”。

**验收顺序：**先用空盒模型逐张对照五张参考图，确认结构和机位；再把同一专辑的八张组件贴到对应位置；最后验证开合、取盘与商品图导出。参考图中局部结构可能存在透视或生成误差，具体加工尺寸以用户实测为准。
