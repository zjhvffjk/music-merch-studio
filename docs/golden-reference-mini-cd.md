# Mini CD Golden Reference 规范

## 目标

以用户确认的三张参考图为 Golden Reference。每次输入一张新的原始专辑封面，先提取该封面的 Visual DNA，再生成一套可印刷的 Mini CD 三件套技术展示板。学习的是输出结构和设计方法，不复制参考图的色彩、人物、场景或具体画风。

设计原则：**Visual DNA Preservation + Medium-Specific Recomposition + Scene Expansion + Controlled Variation + Cross-Asset Consistency**。

## 先提取的 Visual DNA

每张新封面必须提取并记录：

- 主色与辅助色
- 摄影或插画风格
- 人物与主体
- 构图方式与视觉重心
- 光影方向和对比
- 纹理与材质感
- 字体气质
- 情绪、时代感与叙事基调
- 场景元素
- 核心视觉符号

## 固定输出：白底三件套技术展示板

### ① CD 盘面

- 外径 40mm，中心孔 5mm。
- 必须为圆形重新构图；主体与文字主动避开中心孔。
- 保留原封面辨识度，但不直接裁切正封面。

### ② 封面背面 + 封面

- 总尺寸 82 × 41mm。
- 左：封面背面／内页，41 × 41mm；右：封面正面，41 × 41mm。
- 正封面可最接近原作；左侧必须是新的场景延展，不能复制正封面。
- 左侧不放条码、曲目或版权。

### ③ 盒体展开

- 总尺寸 111.2 × 38mm。
- 从左到右严格为：右侧封 4.4mm｜封底 49mm｜左侧封 4.4mm｜左侧封背面 4.4mm｜内盘底 49mm。
- 比例严格为窄｜宽｜窄｜窄｜宽；两块左侧封必须直接相邻，中间不得插入区域。
- 封底：曲目、时长、条形码、版权信息。
- 内盘底：新的隐藏主视觉／延展场景。
- 侧封：标题、歌手名或视觉延展。

## 生产信息与边界

- AI 负责背景、场景、纹理、人物／主体延展和装饰视觉。
- 程序叠加真实信息：专辑名、歌手名、曲目、时长、条形码、版权、尺寸和裁切标记，避免生成模型产生乱码。
- 技术展示板须保留白底、部件编号、尺寸标注、裁切线与折线。

## 禁止项

- 不做立体 Mockup 或桌面摆拍。
- 不改为 Jewel Case。
- 不把五个区域平均分配。
- 不以同一张封面填满所有区域。
- 不改变 Golden Template 的尺寸、顺序或部件职责。
